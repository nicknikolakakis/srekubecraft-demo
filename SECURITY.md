# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in any demo, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, email [nonicked@protonmail.com](mailto:nonicked@protonmail.com) with:

- Description of the vulnerability
- Steps to reproduce
- Which demo is affected
- Any potential impact

You should receive a response within 7 days. We will work with you to understand and address the issue before any public disclosure.

## Scope

This repository contains demo code accompanying blog posts on [srekubecraft.io](https://srekubecraft.io/). While demos are not production services, we take security seriously and will address reported issues promptly.

## Supported Versions

Only the latest version on the `main` branch is supported.
